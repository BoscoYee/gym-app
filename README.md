# HK Gym PWA

This is the Windows-friendly first version of the iPhone gym app.

## How to open

Open `index.html` in a browser for a quick preview.

For full PWA behavior such as service worker caching, serve the folder with any local static server. On an iPhone, open the served URL in Safari and use **Share > Add to Home Screen**.

## Current scope

- iPhone-first responsive layout
- Home, Training, Records, Analytics, Settings
- Local browser storage for user profile and workout records
- Workout flow: warmup, main training, cardio, stretching
- Official LCSD JSON sync button prepared with fallback sample data
